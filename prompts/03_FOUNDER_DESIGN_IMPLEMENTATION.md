# Prompt 03 — Implement Founder-Approved UI

Prerequisite: founder supplies approved Figma frames, screenshots or detailed screen specifications.

Implement only the named screen(s).
1. Inspect existing design tokens and components.
2. Match layout, typography, spacing, color, radius and responsive behavior.
3. Support Urdu RTL and English LTR where specified.
4. Include loading, empty, error, disabled and success states.
5. Use accessible labels and keyboard focus.
6. Use realistic sample data clearly separated from production data.
7. Do not invent visual elements or use random stock images.
8. Add component and browser tests.
9. Capture browser screenshots at agreed viewports and report visual mismatches.

If design input is missing, stop and ask for it rather than inventing a design.
