# Prompt 01 — Architecture and Data Model Proposal

Do not write application code yet.

Using the approved charter and PRD:
1. Produce a Mermaid component architecture diagram.
2. Produce a Mermaid ERD.
3. Produce a complete data dictionary with field types, constraints, indexes and privacy classification.
4. Propose API modules and ownership boundaries.
5. Define product-order and service-order state machines.
6. Define commission-ledger entries and refund adjustment behavior.
7. Identify concurrency and idempotency requirements.
8. Produce Architecture Decision Records in `docs/adr/`.
9. Highlight every decision that needs founder approval.

Do not generate migrations until the founder approves the ERD and data dictionary.
