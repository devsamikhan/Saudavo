# Prompt 04 — Seller Onboarding and Catalog

Implement the approved seller onboarding, store profile, product listing and service listing features.

Before coding:
- Read the PRD and data model.
- List endpoints, tables and screens affected.
- Confirm role and ownership checks.

Requirements:
- Draft/pending/approved/rejected states.
- Admin moderation with rejection reason.
- Seller can only access their own store and listings.
- Product images use private storage and signed upload flows.
- Validate price, inventory, category and listing fields server-side.
- Service packages have immutable snapshots when ordered.
- Add unit, integration and E2E tests.
- Update OpenAPI and docs.

Do not implement payments or checkout in this task.
