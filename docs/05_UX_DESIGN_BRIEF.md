# UX / UI Design Brief

Owner: Founder. The founder creates and approves the visual design. The agent implements only approved designs.

## Product design direction
- Trustworthy, modern, warm and commerce-focused.
- Mobile-first.
- Clear product photography and readable prices.
- Low cognitive load for first-time sellers.
- Urdu RTL and English LTR.
- Accessible contrast, focus states, labels and keyboard navigation.
- Avoid a generic admin-template appearance.

## Required design foundations
- Color tokens.
- Typography scale with Urdu font testing.
- Spacing scale.
- Radius, shadows and borders.
- Buttons, inputs, selects, badges, cards, dialogs and tables.
- Navigation patterns for customer, seller and admin.
- Empty, loading, error, success and disabled states.
- Responsive breakpoints.
- RTL mirroring rules.

## Design handoff requirements
For each approved screen provide:
- Figma frame or reference screenshot.
- Desktop and mobile variants.
- Component states.
- RTL variant where relevant.
- Interaction notes.
- Asset and icon references.
- Responsive behavior.

## Agent implementation rules
- Do not invent new colors, typography or layout.
- Do not replace supplied design with a template.
- Ask for missing assets rather than using random stock imagery.
- Match spacing, dimensions and interaction states closely.
- Capture browser screenshots at common viewport sizes and report visual differences.
